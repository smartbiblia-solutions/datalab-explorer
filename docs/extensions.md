# Additional labs: proposals to evaluate

These were proposals in the recovery material, not demonstrated delivered features. They are not simulated in the current UI.

## Semantic Atlas

Begin with imported, precomputed coordinates and cluster assignments as ordinary fields. Native scatter plus the exact-ID table contract can validate linked cohorts before adding embedding infrastructure. A future semantic pipeline must version model/revision, text fields, chunking, embedding parameters, projection, random seed, missing-text policy and the input dataset. Evaluate multilingual/domain retrieval quality and neighborhood stability; never imply that visual proximity proves a factual relation. New model services require an explicit data-transfer decision.

## Decision Studio

Apply constraints before ranking alternatives. A transparent initial model is `sum(weight × normalized criterion)`, with an explicitly fixed reference population so filtering competitors does not change an unchanged record's score. Store criteria, weights, normalization basis, missing evidence and input version with the scenario. Explain exclusions, reveal sensitivity across plausible weights and support counterexamples, scenario disagreement and evidence dossiers. Do not collapse uncertain evidence into an unexplained score.

## Refresh Observatory, Evidence Graph and review cohorts

Extend the delivered ID/field diff with schema drift, distribution changes and affected pinned cohorts before activation. An evidence graph must distinguish asserted/extracted/inferred relations and preserve provenance; graph selection must use the same exact-ID selection contract. Review cohorts could add annotations, adjudication and version-aware completion before using human labels for automated evaluation.
